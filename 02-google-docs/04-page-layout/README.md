# 04 - Prepare a Professional Page Layout

In this chapter you will set up pages, headers, footers and page numbering; compare pages and pageless use.

> **Prompts and values:** use the [copy-paste page](./prompts.md) for the exact values used below.

**Target allocation:** 50 minutes: 10 explanation/demonstration, 20 guided build and casework, 15 independent challenge, 5 verification and repair. The active portion is 40 minutes by design. These are unmeasured targets awaiting a learner pilot.

**Your result:** An A4 document with checked headers, footers and page numbers.

> **Status:** expanded review draft, revision 0.4. Complete the casework and independent challenge as well as the guided steps. The expanded route, screenshots and timing have not yet been validated in the learner application.

## 4.1 Choose the Document Format

1. Open File, then Page setup. Inspect Pages and Pageless.
2. For this print exercise choose Pages, A4 and portrait. Use consistent margins on all sides.
3. Return to the document and inspect the first page. Discuss when a wide collaborative working document might use pageless instead.

## 4.3 Check Page Breaks

1. Inspect every page for an isolated heading, split table or oversized blank gap.
2. Keep a heading with its following paragraph using the available paragraph pagination options. Use a deliberate page break only where the document needs a new section.
3. Open print preview or download a temporary PDF and check that the page elements remain readable.

<details markdown="1">
<summary>What should you see?</summary>

Every page has usable content, legible page elements and no avoidable blank page.

</details>

## 4.4 Lay Out a Usable Multi-Page Procedure

1. Under the relevant procedure section insert a four-column table: Field, Meaning, Example and Check. Populate TaskID, Owner, Status, DueWeek, Exception note and Source link from the supplied guidance, labelling any designed field as proposed.

2. Use **Table options** to adjust column widths and cell padding. Give the meaning and example columns enough width to avoid one-word lines. Keep the table as a table rather than replacing it with an image.

3. Add a numbered six-step submission checklist as real procedure content. Avoid repeated filler paragraphs to create page length.

4. Inspect how the table and headings cross page boundaries. Where the available controls permit it, retain a useful header row and keep headings with their following explanation.

5. On a practice copy compare A4 portrait with a pageless working view. Record which is easier for editing the field table and which suits the intended printed handout.

6. Return the maintained print version to Pages mode. Check header, footer and automatic page numbers after adding the table and checklist.

7. Export a draft PDF and inspect every page for clipped table columns, isolated headings, blank gaps and unwanted empty pages. Record actual page numbers for any defect and repair at the source.

## Independent Challenge

Close the earlier step lists for the first attempt. Use the case input and your own reasoning. If you need help, record the hint and repeat the affected check independently.

1. The reader now needs an escalation table containing Issue, Evidence, Proposed next action and Confirmation needed. Create at least three meaningful rows from missing owner, unclear status and unapproved budget cases.

2. Fit the new material without reducing the entire document to tiny text. Choose sensible breaks and inspect both the native pages and a fresh PDF.

3. Write a brief layout decision explaining the chosen mode, table widths and one pagination repair.

## Evidence to Hand Over

- Populated six-field reference table and real submission checklist.
- Three-case escalation table placed in a readable multi-page document.
- Page-by-page layout record and inspected PDF after the change.

Record the defect or uncertainty you investigated, the evidence used, the repair or reasoned no-change decision, and the final state. Restore temporary changes or keep them in a clearly named scenario copy.

## Troubleshooting

| Symptom | What to check |
|---|---|
| A wide table is clipped in the PDF | Adjust widths and source page layout, then re-export; inspect the final column on every affected page. |
| An input or earlier result is missing | Reopen the input named in Before You Begin; do not substitute private company data |
| A menu or feature is unavailable | Confirm the account and the shared access notes; record the missing step and ask the trainer for its fallback |
| The result differs from the checkpoint | Compare the exact source range, wording and conditions before repeating the action |
