# Before You Begin

This review book accompanies Google Sheets Fundamental and Intermediate. Work through its chapters in order and keep the original practice inputs unchanged. The same notes and prompts also appear in the local course website.

## Current Status

All chapters in this book are written drafts. Most have not yet been executed end to end in the application. The masterclass's reference brief chapter has a tested core path with a recorded recovery prompt; that does not validate the other exercises. Treat VERIFY notes and draft notices as production work still to complete.

## What You Need

Use a desktop browser and the Google account approved for the class. Confirm app and AI access beforehand. Edition, administrator controls and language can affect availability.

Download the supplied fictional practice pack. No real client or personnel record is needed. Dataset week fields are relative practice weeks, not an agreed pilot start date.

## How to Use the Exercises

Follow the numbered steps, attempt the output and then open the expected-result box. AI wording can vary; source facts and approval conditions must remain correct.

Values and prompts appear directly beneath the steps that use them. Replace source placeholders before submitting. Inspect proposed edits before applying them. Drafting does not authorise sending, inviting people or publishing.

## Course Timing

This course is planned for 1 day, with 390 teaching minutes per day, excluding breaks and lunch. Estimates include practice, checks and discussion and need a classroom pilot.

Each course supplies independent starting inputs. Use a stated recovery file if an earlier output is missing.

## Expanded Casework

Revision 0.4 adds casework, independent challenges and evidence gates to every chapter. The original short guided path alone is insufficient. Timings are targets, not measured learner results. Read each case input and keep baseline and scenario files separate.
