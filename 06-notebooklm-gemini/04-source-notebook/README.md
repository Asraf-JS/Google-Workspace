## 4.4 Audit Citations, Source Selection and Conflicts

1. Before asking more questions, record the three core source titles and inspect their complete imported content. Confirm the source pack matches the manifest.

**Case input to analyse**

Fictional training material. This is exercise content to analyse, not authorisation to send, publish, grant access or change a real project decision.

```text
Conflict extracts, separate test context: A: “Proposed practice A: contributors prepare updates on Friday. Approval not recorded.” B: “Proposed alternative B: contributors prepare updates on Wednesday. Approval not recorded.” Neither establishes an approved replacement for the original project facts. Do not pick an approved day from titles or upload order.
```


2. Run the six-question bank and open the evidence passages for every consequential answer. Record whether the passage supports the exact claim, only nearby context or no support.

**Copy: Evidence Question Bank**

```text
1. What is the pilot’s purpose and duration?
2. Which three teams participate?
3. What reporting cadence and success measure are stated?
4. Is the RM 12,000 ceiling approved?
5. What start date is confirmed?
6. Which preparation actions, owners and due weeks are explicit?
```

Keep source facts separate from inferred workflow. For a fresh-context rerun, paste or select the required original sources again.


3. Select only the meeting record where the interface permits it and ask for actions and budget status. Compare the answer with the full-source response and note scope limitations.

4. Create a separate **Conflict Practice** notebook or clearly separated test context using the two conflicting guidance extracts on the card. Do not contaminate the core evidence notebook.

5. Ask which reporting day is approved. Inspect whether the answer recognises both extracts as proposals without approval evidence, rather than simply choosing the later-looking title.

6. Add a revised practice source using the available update, replacement or new-source route. Open the imported content to prove which version is present; do not assume a saved answer updates itself.

7. Rerun the affected question and compare old answer, current source and new answer. Preserve the evidence trail and label the conflicting-source context separately.

## Independent Challenge

Close the earlier step lists for the first attempt. Use the case input and your own reasoning. If you need help, record the hint and repeat the affected check independently.

1. Write two independent multi-source questions and one missing-fact question. Inspect every cited passage supporting their answers.

2. Challenge one answer with “Which exact source sentence establishes this?” and record any unsupported certainty, including a citation that merely mentions the topic.

3. Produce a source-version and conflict-handling note that another learner can use without guessing which source is authoritative.

## Evidence to Hand Over

- Six-question citation audit with exact claim-to-passage checks.
- Separate conflict context with unresolved authority handled explicitly.
- Verified source-version change and an old-versus-new answer comparison.

Record the defect or uncertainty you investigated, the evidence used, the repair or reasoned no-change decision, and the final state. Restore temporary changes or keep them in a clearly named scenario copy.

## Troubleshooting

| Symptom | What to check |
|---|---|
| A citation exists but does not support the answer | Read the surrounding passage and compare the exact approval/date wording rather than trusting the marker. |
| An input or earlier result is missing | Reopen the input named in Before You Begin; do not substitute private company data |
| A menu or feature is unavailable | Confirm the account and the shared access notes; record the missing step and ask the trainer for its fallback |
| The result differs from the checkpoint | Compare the exact source range, wording and conditions before repeating the action |

## Lesson Summary

Notebook answers become useful when citations are checked against their source context.
