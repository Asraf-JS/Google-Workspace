**Duration:** 1 day. Each day has 390 teaching minutes, excluding lunch and breaks.

**Audience:** New Sheets users with basic browser skills.

## Course Scenario

> Maintain a fictional project task and cost register.

**Your result:** A clean register with calculations, validation, a summary chart and a readable print preview.

## Inputs and Checks

Each lab will include supplied fictional inputs, a named output, a checkable expected result, independent practice and troubleshooting. AI wording may vary; factual checks and assessment criteria will stay fixed.

## Delivery Notes

Basic arithmetic, aggregation and references move into this course so learners have a sound foundation for Advanced. Replace the outline's split-view activity with freezing headers and filter views. Print settings are a manual skill; AI advice is optional.
