# Google Sheets Fundamental and Intermediate

**Status:** review draft, revision 0.4. Labs 1-8 have 213 staged author-reference captures. Browser upload, CSV import and values-only format preservation are unverified (Lab 2's values-only check did not pass in the controlled session and needs a manual retest). Independent challenges, partner review and learner timing are still pending. Each chapter's status note and the [validation status](../planning/VALIDATION-STATUS.md) record the details.

**Duration:** 1 day. Each day has 390 teaching minutes, excluding lunch and breaks.

**Audience:** New Sheets users with basic browser skills.

## Course Scenario

> Maintain a fictional project task and cost register.

**Your result:** A clean register with calculations, validation, a summary chart and a readable print preview.

## Inputs and Checks

Each lab will include supplied fictional inputs, a named output, a checkable expected result, independent practice and troubleshooting. AI wording may vary; factual checks and assessment criteria will stay fixed.

## Delivery Notes

Basic arithmetic, aggregation and references move into this course so learners have a sound foundation for Advanced. Replace the outline's split-view activity with freezing headers and filter views. Print settings are a manual skill; AI advice is optional.

The original guided steps are a starting point. Each chapter now adds a substantive case, independent changed requirement, failure diagnosis and named evidence. Active work is designed for at least 30 minutes per lab; actual pacing is unmeasured. See the [depth and pilot plan](../planning/LAB-DEPTH-AND-PILOT.md). Keep the baseline and scenario copies distinct. The specialist courses use their own starter inputs and do not require outputs from the masterclass.
