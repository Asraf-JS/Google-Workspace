1. Select Tasks A1:I13. Open File, Print and choose Selected cells.
2. Inspect landscape orientation, fit-to-width scaling and whether the header can repeat.

## 7.4 Prepare a Readable, Scoped and Reproducible Output

1. Write an output brief for a contributor who needs working input cells and a sponsor who needs a fixed summary. Identify the intended file and scope for each.

2. Inspect **Share** settings and current inheritance without changing access. Record proposed reader/editor roles separately from actual tested permissions.

3. Select the summary range and choose **File**, **Print**. Compare selected cells, current sheet and workbook scope where offered.

4. Choose orientation and scaling that preserve readable labels. Test repeated frozen rows and page breaks for a multi-page Tasks output when available.

5. Inspect every print-preview page, including the final page. Record whether helper cells, spare tests or unrelated tabs appear.

6. Save a PDF with a clear revision name. Open it and compare count/cost totals and row labels with the maintained source.

7. Change one heading in the working source and demonstrate that the old PDF remains unchanged. Produce a newly named export and update an output manifest.

<details markdown="1">
<summary>What should you see?</summary>

Inspected access settings and proposed-role plan. The result must be supported by the recorded checks; an attractive output or an AI assurance is insufficient.

</details>

## Independent Challenge

Close the earlier step lists for the first attempt. Use the case input and your own reasoning. If you need help, record the hint and repeat the affected check independently.

1. Prepare two independent outputs: a concise sponsor summary and a complete task listing with readable headings. Do not force both into the same one-page layout.

2. Have a reviewer use the manifest to identify the current source and current fixed copy. Repair ambiguous filenames or scope labels.

3. Explain which ranges should be edited, which calculated cells should be reviewed and why a fixed PDF is not a live tracker.

## Evidence to Hand Over

- Inspected access settings and proposed-role plan.
- Two scope-checked readable PDFs with the correct final-page content.
- Source-to-export comparison and a revision manifest that identifies the current copy.

Record the defect or uncertainty you investigated, the evidence used, the repair or reasoned no-change decision, and the final state. Restore temporary changes or keep them in a clearly named scenario copy.

## Troubleshooting

| Symptom | What to check |
|---|---|
| The PDF contains practice/helper content | Inspect selected-cells versus current-sheet/workbook scope and regenerate the intended output. |
| An input or earlier result is missing | Reopen the input named in Before You Begin; do not substitute private company data |
| A menu or feature is unavailable | Confirm the account and the shared access notes; record the missing step and ask the trainer for its fallback |
| The result differs from the checkpoint | Compare the exact source range, wording and conditions before repeating the action |

## Lesson Summary

Checked access and readable output complete the register handover.

**Check yourself:** Which output would automatically reflect later source changes, and which is a snapshot?
