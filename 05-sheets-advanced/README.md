**Status:** review draft, revision0.4. Labs1-10 have347 author-reference captures covering source audit, formulas, rules, text/lookups, pivots, database criteria, dashboards and native Gemini proposal audits. Labs11-12 still need author execution and captures. Independent/human checks and learner timing remain pending.

**Your result:** A reconciled analysis workbook with tested formulas, lookups, pivots and a project dashboard.

## Inputs and Checks

Each lab will include supplied fictional inputs, a named output, a checkable expected result, independent practice and troubleshooting. AI wording may vary; factual checks and assessment criteria will stay fixed.

## Delivery Notes

Use diagnostics to decide whether reference revision can be shortened. Preserve database functions from the supplied outline, but teach them after participants can reconcile totals with simpler tools. XLOOKUP and QUERY may be optional extensions, not extra mandatory topics.

## Expanded Lab Standard

The original guided steps are a starting point. Each chapter now adds a substantive case, independent changed requirement, failure diagnosis and named evidence. Active work is designed for at least 30 minutes per lab; actual pacing is unmeasured. See the [depth and pilot plan](../planning/LAB-DEPTH-AND-PILOT.md). Keep the baseline and scenario copies distinct. The specialist courses use their own starter inputs and do not require outputs from the masterclass.
