## Workbook Layout

TaskRegister: Tasks row 1 contains TaskID, Team, Task, Owner, DueWeek, Status, PlannedCost and ActualCost in A:H. Rows 2:13 are records. Summary contains Status and TaskCount in A:B, with the count cells deliberately blank for the learner.

ProcurementRegister: Orders row 1 contains OrderID, Project, Team, ItemCode, Quantity, UnitCost, Status, Week and Description in A:I. Rows 2:25 are records. Rates has ItemCode, Item, UnitCost and Category in A:D with six records in rows 2:7. Amount and other answer calculations are added during the lessons.

The procurement dataset is separate from the pilot's proposed budget. Neither dataset represents an actual commitment. Week fields are relative practice indexes, so they do not establish the unresolved pilot start date.
