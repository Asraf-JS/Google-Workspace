## What Counts as Completion

Complete the guided build, solve the changed-requirement challenge, inspect the result and repair discrepancies. Retitling a chart or repeating the trainer's clicks does not complete a lab. Each assignment has named evidence for review and a fallback where access differs.

Core topics now include file identity and access planning; factual AI review; styles and decision tables; comments, suggestions and versions; Gmail/Calendar preparation; action extraction; data cleaning, validation, variance, COUNTIF and SUMIF; filter views; linked charts; Slides story and speaker notes; export checks; Sites navigation; permission dependencies; and integrated change/restoration.
